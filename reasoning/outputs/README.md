# Actual reasoning outputs

Generated by `python -m reasoning.evaluate`; the measured summary and all-course results are in `summary.json` and `reachability.csv`. Repeated edges across separate returned paths are counted as separate checks; the edge-check total is not a count of unique triples.

Representative inputs and corresponding real files:

| Input | Saved output |
| --- | --- |
| prerequisite_chain(course='CS421') | chains_CS421.json |
| eligibility(student='S003', course='CS421') | eligibility_S003_CS421.json |
| reverse_unlock(student='S002', course='CS225', concurrent=False) | unlock_S002_CS225.json |
| degree_progress(student='S003') | progress_S003.json |
| degree_progress(student='S004') | conflict_S004.json |
| prerequisite_chain(course='ZZZZ999') | unknown_course.json |
| eligibility(student='S001', course='CS100') | no_prerequisites.json |
| eligibility(student='S001', course='CS421') | failing_student.json |
| prerequisite_chain(course='CHEM202') | cycle_CHEM202.json |
| prerequisite_chain(course='CS421'), max_depth=1 | depth_limit.json |

`inference_examples.json` is generated separately by `scripts.inference_examples`, with actual conclusions, premises and schema axioms. Execution screenshots must be captured from real runs and entered in `report/screenshots/manifest.json`; these files are machine-readable outputs, not screenshots.
