# Representative reasoning executions — Day 5

Run from the repository root with the actual current KG:

```bash
python -m reasoning.examples --case chain
python -m reasoning.examples --case eligibility
python -m reasoning.examples --case unlock
python -m reasoning.examples --case degree
python -m reasoning.examples --case unknown
```

The runner saves each actual input and full result as a JSON file here, with the graph hash, source-file hashes and UTC execution timestamp. It validates every returned path and checks the explicit graph was not changed. It never inserts a stored answer. Re-running a case replaces that case's artifact with its fresh execution. Day 4's benchmark summary is kept separately and is not overwritten.

| Case | Input | Actual artifact generated by the command |
| --- | --- | --- |
| chain | prerequisite_chain, CS421 | chain.json |
| eligibility | eligibility, S003, CS421, 2026-fa | eligibility.json |
| unlock | reverse_unlock, S002, CS225, 2026-fa, concurrent=False | unlock.json |
| degree | degree_progress, S003 | degree.json |
| unknown | prerequisite_chain, ZZZZ999 | unknown.json |

Terminal text shows a compact view; the full paths, alternative groups, blockers and warnings are in JSON. Path IRIs are shortened only on screen. Eligibility and numeric degree conclusions are application-rule results. Explicit/inferred labels refer to RDF evidence. Hypothetical completion is an assumption, not a graph fact or prediction. The degree audit is not an official graduation certification.
