# Prompts

`baseline.txt` and `grounded.txt` are project prompts. ChatGPT was used to assist with code, documentation and prompts, and to cite external code, datasets, ontologies, prompts, libraries, tutorials and other resources. They are not copied from a research paper. Record this assistance in the report and understand/modify them yourselves. `app/service.py` supplies the question and serialized retrieved context; the evaluation manifest hashes both prompts. Store the exact prompts and raw responses for reproducibility. Prompt instructions are a control measure, not proof that a model cannot hallucinate.

For the viva, show the exact two prompts and the recorded provider messages. Explain why the grounded prompt requests graph/row citations, how uncertainty is handled, and why semantic human review is still necessary.
